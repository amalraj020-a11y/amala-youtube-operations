# Privacy policy

Amala YouTube Automation is an owner-operated workflow for the Amala Raj YouTube channel.

The workflow requests the Google `youtube.upload` permission only to upload videos created by the repository workflow. OAuth credentials are stored as encrypted GitHub Actions secrets. The project does not sell personal data or give credentials to advertisers.

The repository stores production logs, generated media evidence, and confirmed YouTube video identifiers. It does not intentionally publish OAuth tokens, passwords, API keys, private messages, or unrelated Google Account data.

Access can be revoked at any time from the Google Account connections page. Questions can be sent to the support email displayed on the Google consent screen.

Last updated: 2026-10-19.
